# The Odin Project - Testing Practice

This is a testing practice project for [The Odin Project](https://www.theodinproject.com/) JavaScript course, based on the JavaScript Testing chapters.

## Assignment

Write tests for `capitalize`, `reverseString`, `calculator methods`, `Caesar cipher` and `analyzeArray` functions following [Test Driven Development](https://en.wikipedia.org/wiki/Test-driven_development) methodology.

## Things I Used

- Jest for testing
- Babel for converting CJS to ESM

## What I Learned

- How to write unit tests
- How to use Jest matchers
- What is TDD methodology
